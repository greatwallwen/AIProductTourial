# Markdown 课程重构记录

本轮只处理课程正文。原稿的知识点和案例事实大多可用，阅读困难来自结构：9.3 万字符里有 333 个标题，24 个案例重复七个同名栏目，Prompt 与 Skills 又以小卡片反复打断。重构保留模块化源文件与确定性单文件输出，开篇改用锅炉低温事件引出全课；理论章节增加前后衔接；Prompt 改为连续六步；24 个案例分成四组，每案用三个随场景变化的标题串起问题、数据、页面、Prompt、操作和排查。

第一轮检查暴露了旧验证器仍把重复栏目当成课程质量。验证规则随后改为检查三段叙事是否唯一、Prompt 与三张图是否保留、案例是否可运行。第二轮又发现可见 Prompt 编号从 P003 跳到 P005，以及大量“不是 X，而是 Y”和内部运行记录链接；这些已改成连续六步和自然表述，原始 JSON 退出正文，经营简报、PPTX、SVG、截图和检查申请继续保留。

最终单文件为 94,051 字符、196 个标题，标题最大重复次数为 1；公式化对照句从 26 处降到 1 处。18 个 Prompt 实验、9 个 Skills、4 个 Loop、24 个案例、24 张运行截图和 48 张中文流程/架构图全部通过检查。数据仍为 27 组、43 个编号、100,612 条记录；代码、数据、资产和 PowerPoint 没有改动。没有新增缓存或临时浏览器目录，下一步只发布当前分支并等待实际授课阅读反馈。
