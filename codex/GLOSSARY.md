# 统一术语表

本文件规定全书核心术语。章节需要更精确的领域定义时，应在不冲突的前提下补充，并在这里登记。

## Model / 模型

接收输入上下文并生成输出的机器学习模型。本书中的“模型”不包含工具执行、持久化状态或循环控制器。

## Context / 上下文

一次模型调用时可见的信息集合。上下文不是自动持久化的数据库，也不等同于长期记忆。

## Prompt / 提示词

放入上下文、用于描述目标、约束、输入和输出要求的信息。提示词是系统的一部分，不等于完整系统。

## Tool / 工具

由模型建议或选择、但由外部程序实际执行的能力，例如读取文件、查询数据库或调用 API。模型提出工具调用不代表模型亲自执行了工具。

## MCP / Model Context Protocol / 模型上下文协议

连接 AI 应用与外部工具、资源和提示模板的开放协议。MCP 提供连接方式，不自动构成 Agent 或 AI Loop。

## Agent / 智能体

能够获取当前状态、调用模型决定下一步、在权限范围内执行行动、观察结果，并按控制条件继续或停止的完整运行系统。

## AI Loop / AI 循环

系统重复执行“观察 → 生成或选择行动 → 执行 → 获取结果 → 验证 → 判断继续或停止”的控制过程。

## State / 状态

系统为后续决策显式保存的当前事实、历史结果和控制信息。状态不等同于模型上下文。

## Memory / 记忆

跨步骤或跨会话保存、检索并重新注入相关信息的机制。记忆必须有写入、检索、更新和清理规则。

## Validation / 验证

用可观察证据判断结果是否满足约束和验收标准的过程。模型自评可以是信号，但不能天然视为客观验证。

## Eval / 评测

使用固定任务集、指标和判定方法，重复衡量系统质量与回归的机制。

## Skill / 技能

把特定任务所需的判断、步骤、约束和资源组织成可复用执行单元的工程化载体。

## Retrieval-Augmented Generation (RAG) / 检索增强生成

系统先从外部知识源检索与当前问题相关的内容，再把检索结果放入模型上下文辅助生成。检索增强生成解决“需要时查到相关知识”的问题，不负责保存任务进度、执行历史或停止状态。

## Human intervention / 人工介入

人在目标定义、行动授权、结果复核、异常处理或权限升级等明确位置参与系统运行的控制方式。人工介入必须说明由谁、在什么条件下、依据什么信息做出什么决定，而不是笼统地“有人看着”。

## Stop condition / 停止条件

使循环结束的显式规则，包括任务完成、失败、人工终止、预算耗尽或达到最大迭代次数。
