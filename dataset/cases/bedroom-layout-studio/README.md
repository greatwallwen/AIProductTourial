# 家具试摆：模拟输入与图像来源

`room-data.json` 和 `room-plan.svg` 是同一组人为模拟输入，不来自真实住宅测量，也不代表在售家具尺寸。图中原有家具、门窗和房间尺寸固定；页面可另选候选书桌并调整摆位。最终工程的 `code/cases/bedroom-layout-studio/skill-web-artifacts-builder/src/room-data.json` 使用相同固定数据；房间示意图用于解释输入，不能据此推断真实户型。

| 对象 | 模拟尺寸（厘米） | 原始位置或开口 |
|---|---|---|
| 房间 | 420 × 330 | 坐标原点在左上角 |
| 床 | 150 × 200 | (25, 20) |
| 衣柜 | 120 × 60 | (290, 20)，距右墙 10 |
| 床头柜 | 45 × 45 | (190, 35) |
| 窗 | 宽 130 | 北墙从 x=160 起 |

书桌 A、B、C 的模拟宽 × 深分别为 100 × 55、120 × 60、140 × 70。俯视图示中的枕头、柜门、桌面物件只是辨认用途，不是额外测得的家具构造。
