# 县域冷链温度偏差调查与质量会签台

- 数据性质：`public-thermal-benchmark-plus-deterministic-synthetic-cn-operations`
- 课程子集：`case.csv`，360 行
- 来源 ID：DATA-12, POLICY-12, COURSE-OPS-12
- 生成命令：`python transform.py`

## 这些数据能说明什么

- public-benchmark.csv 是尼泊尔公开热性能数据，case.csv 是中国县域确定性合成运营事件，两者不伪造站点映射。
- 任何温度筛查或调查结案都不能自动判定产品可用、失效或放行。

原始下载、许可和固定版本见 `source.json`。
