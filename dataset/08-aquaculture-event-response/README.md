# 中国养殖水质事件响应数据

本目录把两种性质不同的数据明确分层：

- `geo-assets.csv`：DATA-08A 中国典型沿海养殖塘 GeoTIFF 的 38 条公开资产索引，许可为 CC BY 4.0。
- `case.csv`：864 条确定性课程运营序列，固定标注为 `deterministic-synthetic-cn-operations`，不是养殖场生产记录。

## 复算

在本目录运行：

```powershell
python -B transform.py
```

脚本从 `geo-assets.csv` 为每个区域选择最新空间资产，以 2026-06-01 起连续 96 小时的固定温度曲线、区域偏移和规则化扰动生成运营序列。脚本不读取网络、不读取哥伦比亚数据、不使用随机数；相同输入会得到相同 `case.csv` 与 `eval.jsonl`。

脚本同时为 38 条离线、来源缺失或数值冲突事件生成 `repair-evidence.jsonl`。每条修复证据保存事件、空间资产、版本、状态、原数据哈希、修复后数据哈希、数据性质和证据指纹。运行页只使用服务端数据加载器装载且通过固定指纹核验的对象，浏览器不能自行把异常事件改写成正常状态。

## 字段与关系

每条事件包含事件编号、带中国时区的时间、`region_id + archive_member`、水温、溶氧、pH、浊度、传感器状态、证据状态、风险等级、控制权限和数据性质。`region_id + archive_member` 只表示课程事件引用了哪项公开空间资产，不代表该位置部署了真实传感器。

`geo-assets.csv` 中的 `row_level_link_to_sensor=False` 表示 DATA-08A 没有提供真实传感器主键。本案例新增的是可复算的课程运营关联，不得改写成真实现场关联。

## 处置边界

- 来源缺失、传感器离线或数值冲突必须进入 `evidence_deferred`，修复后才能重试。
- 调度员负责确认、派单和关闭；现场人员只提交观察记录。
- 页面角色切换只是本地流程模拟，不是生产环境的身份认证或授权系统；领域动作仍会校验角色与状态。
- 禁止自动投药、自动增氧、鱼病诊断和因果归因。

固定来源、许可、生成方式和排除项见 `source.json`；字段合同见 `schema.json`。
