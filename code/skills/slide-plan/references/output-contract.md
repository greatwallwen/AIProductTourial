# Slide plan output contract

Markdown uses one `#` deck title and one `##` heading per following slide. Optional directives are single-line comments:

```markdown
<!-- layout: section -->
<!-- notes: Speaker notes for this slide. -->
<!-- source: dataset/06... or course-local input -->
<!-- graphic: quality-flow | Three states with a human-review exit. -->
```

A Markdown table creates an editable PowerPoint table. A `graphic` directive creates an editable named placeholder, not a fake completed visual.

`slide-plan.json` records slide number, kind, title, Markdown source line, speaker-note source, content budget, and table or graphic placeholder contracts.

`visual-qa.json` is generated by the Artifact Tool build. It passes only after every slide renders and the deterministic bounds, overlap, and text-capacity checks report no issue. Per-slide PNG and layout JSON files remain under the requested render directory.

`structure-audit.json` passes only when:

- the deck has at least five slides;
- every slide has a named title and non-empty speaker notes;
- every notes page includes `[Sources]`;
- every planned table or graphic placeholder exists under the expected object name;
- no slide is blank.
