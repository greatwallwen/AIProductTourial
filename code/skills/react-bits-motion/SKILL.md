# React Bits 动效接入

先写清动效要表达的状态，再选择组件。没有状态含义时停止，不添加动效。

## 步骤

1. 记录目标页面、状态变化、触发动作和静止时仍需看懂的内容。
2. 从 React Bits 只选一个最小组件，固定来源提交并核对许可证。
3. 把组件放进产品自己的命名、颜色和布局系统；不要照搬演示站视觉。
4. 保留键盘操作、焦点样式和 `prefers-reduced-motion` 降级。
5. 检查首次渲染是否确定，不得用 `Date.now()`、`Math.random()` 或客户端分支改变服务端 HTML。
6. 运行聚焦测试、类型检查和真实浏览器检查，确认控制台没有异常。

## 交付

- 状态与动效对应表；
- 固定提交、组件路径和许可证；
- 适配后的组件与样式；
- 键盘、降级、刷新和控制台检查结果。

课程示例固定使用 React Bits `SpotlightCard`，来源提交为 `b9158acb37e7bdfd6c5bc5894da1826fe1d05a6b`。它只强调当前能力说明，不负责制造全屏动画。许可证副本位于 `assets/vendor/react-bits/LICENSE.md`。
