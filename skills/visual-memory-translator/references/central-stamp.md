# Central In-place Stamp / 中央原位邮票

把最终摄影底图中央的一块现实，原位转译成另一种艺术媒介。邮票不是独立插画、二次取景或放大的局部，而是同一画面同一坐标上的媒介替换。

## Spatial invariant（硬约束）

1. 先从原图完成一次最终裁切；裁切时让有叙事性的对象或结构经过中央候选区。
2. 构图锁定后，在视觉重心附近选一个中小矩形，面积默认不超过全图 25%。
3. 框内像素语义来自底图同一位置：不再次裁切、缩放、位移、旋转、居中或补画。
4. 同一对象全图只能出现一次。跨边界的道路、人物、动物、车辆、建筑、树枝、水线与阴影必须在边界处连续。
5. 齿孔与纤细纸边是覆盖层，不能通过缩小内部图像来腾出白边。

最强约束：**框内内容以 1:1 尺寸留在原坐标，只改变媒介，不改变对象的数量、位置、比例、方向、透视和遮挡关系。**

## Artistic translation

框内不是照片滤镜。根据原图材质、结构、色彩、光线与情绪，自选一种与近期结果差异明显的媒介：彩铅、蜡笔、清线漫画、水彩、木刻、石版画、孔版印刷、丝网套色、钢笔淡彩、旧书插图、剪纸、平涂卡通或油墨版画。

主动删除约 60%–80% 次要细节，只保留空间骨架、主体轮廓、运动方向、明暗关系与关键色彩。通常用 3–7 个主要形块、2–4 种主色和少量决定性线条。允许概括和省略；但边界处的主体位置、外轮廓与方向必须接续。

## Stamp layer

- 邮票宽度约为全图 38%–50%，高度约 30%–45%，以面积不超过 25% 为最终约束。
- 使用纤细白色纸边、规则齿孔、极轻纸张厚度；不要粗白框或巨大投影。
- 文字总面积不超过全图 3%，放在框内原本安静的位置。
- 标题、短注、概念编号和半透明邮戳必须来自可见内容；未知地点、日期、人物身份和机构不得虚构。
- 邮戳可轻微跨过齿孔，但不能遮挡主体。

## Avoid

- 框外有一个对象、框内又复制一个对象
- 独立邮票插画贴在照片上
- 框内主体重新居中或放大
- 为白边缩小内部画面
- 仅做滤镜、写实手绘复刻或逐像素描摹
- 邮票覆盖大部分照片、过量文字、廉价复古素材
