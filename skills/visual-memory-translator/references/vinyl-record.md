# Vinyl Record In-situ / 黑胶唱片实景

把同一段摄影记忆转译成一张真正存在于唱片店场景中的黑胶专辑。默认成品为 1:2 竖图，由上下两个等大的正方形组成。

```yaml
style_mode: vinyl_record_in_situ
original_display_mode: split_top_bottom
layout_mode: equal_square_stack
preview_mode: skip
ratio: 1:2
```

## Upper square — photographic evidence

- AI 根据主体、动作、视线、空间结构与色彩锚点选择最佳正方形裁切。
- 可舍弃边缘和无关背景，但保持摄影真实性；不重绘、不改人物身份、动作、天气或物件关系。

## Lower square — new record-store scene

- 必须为新设计的唱片店微距摄影，不复刻上一张输出的货架、机位、灯光或道具组合。
- 专辑封套是最清晰焦点；周围可见正在旋转的黑胶、沟槽、标签、转轴或唱臂。
- 其余环境以浅景深虚化。使用 1970s 模拟质感：暖色钨丝灯、木架、纸张纤维、轻胶片颗粒、透明保护袋或少量金属部件。
- 做旧是被妥善收藏后的使用痕迹：轻微环形磨损、细小划痕、褪色油墨、软化边角；禁止重度污损。

## Album cover translation

不能把原图直接贴在封套上。先读图，再提取主体轮廓、动作方向、空间分区、标志性色彩与光线关系，以 70 年代现代主义、丝网印刷、摄影拼贴、几何重组、专色色块、网点或局部剪影重新设计。

标题每张重新生成，2–5 个词；注释是一句与可见内容有关的短句；目录编号为虚构概念编号。优先英文；若图中存在明确地域语言线索，可使用对应语言。不得虚构歌手姓名、真实厂牌、地点或日期。所有文字拼写准确，只出现指定信息。

## Avoid

- 直接把照片贴到封套
- 重复上一张唱片店的场景与构图
- 专辑不是焦点、唱片静止不可信、现代电子设备抢镜
- 霓虹怀旧滤镜、过度破损、随机乱码、虚构真实艺人或厂牌
- 上下不是两个等大的正方形
