# 术语表

遇到概念时回查即可，不需要按顺序讲授。

| 术语 | 在本课程中的含义 |
|---|---|
| Token | 模型处理输入与输出时使用的计量单位；实际字数与 Token 数并非固定换算。 |
| 上下文窗口 | 一次请求中模型能看到的指令、资料、工具结果和历史内容总量。 |
| Prompt | 对本次工作的目标、输入、输出、限制和检查方法的说明。 |
| Agent | 根据当前结果选择下一步、调用工具并决定继续或停止的执行者。 |
| Skill | 可重复使用的方法包，说明何时使用、需要什么、怎样执行和检查。 |
| Tool | Agent 能调用的类型化能力，例如读取数据、检索资料或生成文档。 |
| Grill | 先查材料，再追问真正会改变范围、架构、安全或验收的决定。 |
| Harness | Agent 工作时可见的项目地图、工具、反馈、约束、权限和恢复点。 |
| Loop | 根据可观察结果继续、修改、等待或停止的工作循环。 |
| RAG | 先从资料中检索相关片段，再把片段交给模型生成回答。 |
| Agentic RAG | Agent 会检查检索缺口、改写查询、补查，并在材料满足条件时停止。 |
| Embedding | 把内容表示成向量，用于相似度检索；相似不等于事实正确。 |
| MCP | AI 应用发现并调用外部工具、资源和提示模板的集成协议。 |
| A2A | 独立 Agent 之间发现能力、发送消息、交接任务和产物的协议。 |
| 质量属性场景 | 用角色、触发、环境、系统反应和指标描述性能、安全、恢复等要求。 |
| C4 | 从系统上下文、容器、组件到代码逐层观察同一系统的架构方法。 |
| DDD | 用领域语言、限界上下文、聚合和事件组织业务规则。 |
| 不变量 | 无论从哪个入口操作都必须成立的业务规则。 |
| ADR | 记录架构问题、约束、选择、代价和重新评估条件的短文档。 |
| 命令 | 希望系统执行的动作，可能因为状态、权限或输入而被拒绝。 |
| 领域事件 | 已经发生的业务事实；同一事件重复到达时不应重复产生业务结果。 |
| 幂等 | 同一请求或事件重复处理，最终业务结果仍与处理一次相同。 |
| 防腐层 | 把外部系统的字段和含义翻译成本领域语言的边界。 |
| 提示注入 | 资料中的文字试图冒充系统指令或获取工具权限。检索内容只能作为数据。 |
| 评测 | 用固定样本和明确检查项比较 Prompt、模型或 Skill 的输出。 |
| 确定性合成数据 | 按固定规则生成、可重复得到且明确标注为合成的数据。 |

概念的来源与延伸阅读见 [rules/references.md](../rules/references.md)。
